CARE+ HOSPITAL — University Demo Website
============================================

Open index.html in a browser.

Pages:
- Home
- Doctors (search + filter)
- Departments
- Book Appointment
- Patient Portal
- About Us
- Contact

The appointment form uses browser localStorage for demo purposes.
No backend/database is required for this university presentation.

If the hero image is not present, the layout still works; assets/hospital-hero.png is an optional visual asset.
